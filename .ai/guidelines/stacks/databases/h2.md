# H2 Database Tech Stack Standards

> **Stack Profile**: Database / H2 Database Engine 2.x (In-Memory & TCP Server)

---

## 1. Syntax & Dialect Limitations
1. **No Partial / Predicate Indexes**:
   - H2 2.x does **not** support predicate clauses in index definitions (`CREATE UNIQUE INDEX ... WHERE is_deleted = false` is invalid syntax).
   - Invariant: When target DB is H2, unique indexes must be standard, and soft-delete uniqueness checks **must be implemented in application service logic**.
2. **Identity Sequence Realignment**:
   - When seed migrations insert explicit IDs, H2 identity columns must be manually reset:
     ```sql
     ALTER TABLE table_name ALTER COLUMN id RESTART WITH 1001;
     ```

---

## 2. TCP Server Container Properties
1. **Remote Database Creation (`-ifNotExists`)**:
   - The H2 TCP server container (`oscarfonts/h2`) refuses remote connections attempting to create non-existent databases unless `-ifNotExists` is passed.
   - Compose files must configure:
     ```yaml
     environment:
       - H2_OPTIONS=-tcp -tcpAllowOthers -tcpPort 9092 -web -webAllowOthers -webPort 8082 -ifNotExists
     ```
2. **Healthcheck Contract**:
   - Use the Web Console port 8082 or TCP port 9092 for the container healthcheck:
     ```yaml
     healthcheck:
       test: ["CMD-SHELL", "nc -z 127.0.0.1 9092 || exit 1"]
       interval: 3s
       timeout: 3s
       retries: 10
     ```
