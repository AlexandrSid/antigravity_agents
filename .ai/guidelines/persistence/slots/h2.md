# H2 Database Persistence Slot Implementation

> **Layer**: `persistence`  
> **Implements**: `.ai/guidelines/persistence/META.md`  
> **Target**: Database / H2 Database Engine 2.x (In-Memory & TCP Server)

---

## 1. MIGRATION_TOOL_AND_NAMING
- **Tool**: Flyway
- **Location**: `src/main/resources/db/migration/`
- **File Pattern**: `V{version}__{description}.sql`

## 2. PARTIAL_INDEX_SUPPORT
- **No Partial / Predicate Indexes**:
  - H2 2.x does **not** support predicate clauses in index definitions (`WHERE is_deleted = false` is invalid syntax).
  - Invariant: When the target DB is H2, unique indexes must be standard, and soft-delete uniqueness checks **must be implemented in application service logic**.

## 3. SEQUENCE_REALIGNMENT_SYNTAX
When seed migrations insert explicit IDs, H2 identity columns must be manually reset:
```sql
ALTER TABLE links ALTER COLUMN id RESTART WITH 1001;
```

## 4. CONTAINER_HEALTHCHECK_CONFIG
For the TCP server container (`oscarfonts/h2`), `-ifNotExists` must be passed in environment options, and port 9092/8082 used for healthchecks:
```yaml
environment:
  - H2_OPTIONS=-tcp -tcpAllowOthers -tcpPort 9092 -web -webAllowOthers -webPort 8082 -ifNotExists
healthcheck:
  test: ["CMD-SHELL", "nc -z 127.0.0.1 9092 || exit 1"]
  interval: 3s
  timeout: 3s
  retries: 10
```
